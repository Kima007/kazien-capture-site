# Kaizen Capture — Website Setup

## What's in this folder
- `index.html` — the whole site (one file, easy to edit)
- `CNAME` — tells GitHub Pages to serve this at kaizencapture.com

## 1. Put it on GitHub Pages
1. Create a GitHub account if you don't have one.
2. Create a new repository — name doesn't matter (e.g. `kaizen-capture-site`).
3. Upload `index.html` and `CNAME` to the repo (drag-and-drop works, or "Add file → Upload files").
4. Go to **Settings → Pages** in the repo.
5. Under "Build and deployment," set Source to **Deploy from a branch**, branch `main`, folder `/root`. Save.
6. GitHub will give you a `https://yourusername.github.io/...` URL once
